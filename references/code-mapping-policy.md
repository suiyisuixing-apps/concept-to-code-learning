# Code mapping verification

Resolve every path inside the authorized repository and reject escapes. Record its
commit and file hash. Parse Python with AST without importing target code. Validate
symbol type and exact line range, and separately locate related tests. A name match
or file existence does not establish conceptual relevance. Record the mapping reason
and distinguish a manually predefined fixture link from a future generated candidate.
Missing symbols, invalid syntax or insufficient semantic support cannot become VERIFIED.
