# Exercise grading

Specify the learning objective, allowed edit paths, starting revision, deterministic
grader command, and acceptance behavior. Keep a known-correct and known-incorrect
solution; graders must accept and reject them respectively. Hidden tests are separate
from learner instructions. Model feedback may explain failures but cannot replace tests.
Record tested commit/file hashes, grader hash/version, exit code, and result. Phase 0
executes a fixture test only and does not claim a graded learner exercise.
