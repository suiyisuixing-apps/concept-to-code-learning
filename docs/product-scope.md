# 冻结的比赛 MVP 范围

目标角色只有新入职后端工程师。输入限 PPTX、DOCX、PDF 和一个授权的本地
Python/FastAPI 代码仓库。每次学习闭环包含 3–5 个知识点，每个至少一个真实代码映射，
至少一个真实可运行示例、一个项目练习、确定性测试验收和一个资料与代码漂移案例。

完成闭环：培训资料 → 保留来源的知识点 → 真实代码与测试 → 验证映射 → 项目化讲解
→ 实际运行示例 → 测试验收练习 → 漂移报告与可审计学习证据。

## Phase 0 与目标能力

Phase 0 只交付工程基础、Skill 说明、公共 Schema、协作系统、CLI 与合成 Smoke Demo。
Markdown 仅是 Phase 0 的固定测试 Fixture，不增加比赛 MVP 的输入格式承诺。
一个预定义知识点通过真实函数和 pytest 证明接口接通，不能宣称已完成 3–5 概念 MVP。
本轮不实现通用文档理解、智能映射、完整教学系统或复杂前端。

后续完整集成要求一次命令输出六类产物：概念映射、讲解、示例包、练习与评分器、
学习证据、漂移报告。范围变更必须经对应 Issue 与 Lead 审核记录。
