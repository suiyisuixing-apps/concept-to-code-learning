# 产品范围

Concept-to-Code Learning 面向正在学习技术材料的学生、自学者与工程人员。任务是理解当前文档知识点、核对真实 GitHub 实现，并保存个人笔记。

目标流程：PDF/PPTX/DOCX/Markdown → 当前页/章节/选区 → 问题与难度 → 技术概念 → 授权的来源范围 → 固定 Commit 的最小代码证据 → 讲解与来源 → 用户显式保存。

三种来源模式：用户指定的 GitHub 仓库、授权的本地只读仓库、明确允许后的公开 GitHub 搜索。搜索与验证分开；任意检索结果都不能自动成为已核验来源。

当前 Phase 0.5 只实现合成 Markdown 分页、依赖注入固定讲解、一条独立核验的 FastAPI 冻结引用和本地笔记。真实解析、实时检索、一般化核验、模型、运行验证、比较属于后续 Issues。Fixture 不证明完整 MVP。

旧企业入职定位已废止，详见 rescope-decision.md。学习效果由未来 Grounding 对照评测评估，不自动给用户贴“掌握知识”的标签。
