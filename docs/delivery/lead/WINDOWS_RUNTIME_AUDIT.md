## 已停止的模型实验

用户授权后已安装 Qwen3.5-9B 和 Qwen3.5-35B-A3B 的 Q4_K_M，来源为 Unsloth GGUF，
不是 Qwen 官方 GGUF 发布；两者与原 7B 的来源、固定 revision、文件校验及许可在本机
各模型目录的 `INSTALLATION.json` 中。35B 权重约 22.02 GB，运行时将部分专家权重置于
CPU 内存；不能称作整个模型完全进入 8 GB 显存。全部下载文件保留，服务现已停止。

固定源码/问题对照中，9B 出现 JSON 格式问题；使用服务侧 JSON grammar 后结构解析通过，
语义仍有错误。35B 的 10 次对照均解析成功，首段约 8–23 秒、完成约 15–38 秒；
二分查找答案有所改善，但反向传播仍出现不正确的导数记号。
结构通过、模型更大或来源引用正确均不等于知识讲解正确。没有将差异归因于 Windows/Mac。
受限思考与新请求选项的联合实测尚未执行，后续因用户决定暂停。
