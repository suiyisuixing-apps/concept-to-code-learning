# 相邻产品类别与项目边界

产品名称清单来自任务提示，仅用于界定需要比较的类别。本轮未进行完整市场调查，
也未逐项验证各产品当前能力、版本、价格或功能缺失。

| 相邻类别 | 待比较对象 |
| --- | --- |
| 文档与仓库上下文辅助 | GitHub Copilot Spaces、Gemini with GitHub import、Claude Projects、ChatGPT with GitHub |
| 代码理解与文档 | DeepWiki、Swimm、CodeSee、GitBook |
| 学习资料辅助 | StudyFetch、Mindgrasp |

本项目不能只实现文档与代码放进同一聊天、普通仓库问答、课件摘要、普通知识点解释或代码导览。
目标能力需同时满足：知识点带页码/章节；真实代码符号映射；文件系统/AST 验证；
示例真实执行；练习确定性测试验收；文档与代码漂移检测。

不作“全球首创”或“市场上完全没有”的声明。差异需用同一资料和仓库上的对照评测证明，
后续 #28 分离来源准确度、符号有效率、执行成功率、测试验收率与漂移检出情况。
